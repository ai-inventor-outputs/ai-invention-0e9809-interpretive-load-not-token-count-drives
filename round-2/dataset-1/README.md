## Layman Summary

A small set of reworded math-word-problem prompts that separates plain rephrasing from added checklist-style instructions, so later tests can tell which part changes an AI's answers.

## Full Summary

This dataset decomposes the prior GSM8K 'relevant elaboration' prompt condition into two isolated sub-conditions -- paraphrase_only (a pure reworded restatement of the problem, same numbers/constraints/question, no added scaffolding) and paraphrase_scaffolding (the identical paraphrase plus the same generic verification-scaffolding sentences used in the original elaboration condition: double-check your units, verify each step, make sure the final answer is consistent with the constraints stated above) -- for 8 GSM8K test-split seed problems, giving 16 total rows. Seeds were pulled fresh from HuggingFace openai/gsm8k (config=main, split=test) and selected as a fixed, hand-picked set of 8 indices chosen for diversity of reasoning-hop count (2-4 hops), arithmetic-operation mix, and answer magnitude (8-200); the upstream artifacts that defined the original bare/filler/elaboration seed set were not available as a dependency to this executor, so this seed set is a clearly logged best-effort approximation rather than a guaranteed exact match to those prior conditions (see README.md approximation_note). Both sub-conditions are length-matched to each other and to the prior 'medium' elaboration tier (~250 added cl100k_base tokens beyond the bare question, tokenized with tiktoken), within a tolerance of max(15 tokens, 10% of target) -- paraphrases were padded with generic, numerically-inert filler sentences when short, and trimmed (never touching the scaffolding text) when scaffolding pushed the combined prompt over tolerance. Every prompt was checked for zero numeric leakage (no digits in added/inserted text beyond the original problem's own numbers) via regex, and gold answers were preserved exactly from GSM8K's '#### <answer>' format. Output follows the exp_sel_data_out schema (input/output plus metadata_fold, metadata_content_type in {paraphrase_only, paraphrase_scaffolding}, metadata_seed_id, metadata_tier, metadata_token_count, metadata_added_token_count, metadata_n_hops, metadata_gold_answer) and is schema-validated. Data is intentionally small (16 rows) since it feeds a low-N follow-up sampling experiment isolating which sub-component (paraphrase vs. scaffolding) drives prompt-length-related answer destabilization, not a large-scale corpus.
