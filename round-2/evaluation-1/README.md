## Full Summary

This evaluation artifact re-analyzes the 336-row (prompt,model) dataset produced by the prior experiment (art_tqod35nIRuWp), which measured how content type (bare/filler/relevant-elaboration) and length tier (short/medium/long) affect the coefficient of variation (CV) of GSM8K numeric answers across 3 OpenAI-hosted models, replacing raw point estimates over 7 condition-mean rows with defensible inferential statistics. eval.py implements: STEP 0, a blocker check confirming full_method_out.json, prompt_model_results.csv (336 rows), and raw_completions.jsonl (6,720 lines) all exist and parse; STEP 1, building a tidy per-(prompt,model) DataFrame (332 rows after dropping 4 rows with NaN CV from division-by-zero when the mean answer was 0) plus a long-format raw-completions DataFrame. METRIC 1 computes the paired relevant-minus-filler CV delta per seed (averaged across the 3 models), then a cluster (block) bootstrap over the 16 seed_ids (10,000 resamples) giving a 95% CI per length tier, plus a paired Wilcoxon signed-rank test and a pooled seed-by-tier cluster version; result: the gap is CI-positive only at the medium tier, and crosses zero at short/long, so the claim is REMAINS_DESCRIPTIVE per-tier but the pooled cluster CI excludes zero. METRIC 2 computes cell-level (n=332, not 7 condition means) Pearson and Spearman correlations between CV and two entropy proxies (mean_entropy_first_k, answer_token_entropy), each with both a naive row-level bootstrap CI and a seed-cluster bootstrap CI (flagging the former as anti-conservative), plus the same 4 correlations recomputed within each content_type subset to test whether entropy tracks CV beyond just tracking condition membership; result: cell-level r=0.284 (CV vs mean_entropy_first_k) and r=0.260 (CV vs answer_token_entropy), both cluster-bootstrap CI-positive, and within-condition signal survives (not purely a between-condition artifact), so this claim is STATISTICALLY_SUPPORTED. METRIC 3 produces a per-model x (content_type,length_tier) breakdown table (mean CV, both entropy proxies, frac_correct, n) and re-runs the Metric 1 paired bootstrap separately for each of the 3 models to check whether the pooled pattern is driven by one model. METRIC 4 computes MAD/median and 5%-trimmed CV per (prompt,model) cell from the raw per-sample answers (flagging cells with n_valid_samples<10 as too-small-to-trim) and re-runs the Metric 1 cluster-bootstrap gap using MAD and trimmed-CV in place of standard CV, comparing all three side-by-side per tier; result: gap direction agrees across all three dispersion measures in 2 of 3 tiers, so this claim is REMAINS_DESCRIPTIVE. METRIC 5 checked the run's artifact tree for a newer 4-condition decomposition artifact (paraphrase-only vs paraphrase+scaffolding vs original elaboration vs filler); none was found, so this metric was explicitly skipped (not blocked). eval_out.json (schema-validated against aii-json's exp_eval_sol_out, PASSED) contains: a metrics_agg block with the key numeric point estimates/CIs/p-values for direct downstream consumption; a metadata block with full nested results for all 4 executed metrics plus the Metric 5 skip reason; a narrative_verdicts_per_hypothesis_claim block giving an explicit STATISTICALLY_SUPPORTED/REMAINS_DESCRIPTIVE/BLOCKED verdict for each of the 3 original hypothesis claims (elaboration-destabilizes-more-than-filler, entropy-correlates-with-CV, gap-robust-to-outliers); a superseded_prior_draft_numbers list telling downstream paper-writing exactly which old unqualified numbers (the condition-mean r=0.75/r=0.59 correlations, the raw per-tier CV point estimates) must stop being cited in favor of the new cell-level/CI-qualified figures; and one example per (prompt_id,model) row in the datasets array carrying the row-level CV/entropy/frac_correct values. All numbers are reproducible: RNG seed fixed at 12345, 10,000 bootstrap resamples throughout, no new LLM calls made (pure re-analysis, $0 spend).
